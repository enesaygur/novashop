# 🛍️ NovaShop

A modern e-commerce application built with **React** and **TypeScript**.
NovaShop focuses on clean architecture, reusable components, state management, form validation, and a responsive user experience.

## ✨ Features

### Customer

* Browse products
* Product detail page
* Search products
* Filter by category
* Sort products
* Shopping cart
* Wishlist
* Checkout form
* Responsive design

### Authentication

* Login
* Logout
* Protected routes

### Admin

* Create product
* Edit product
* Delete product
* Product validation with React Hook Form & Zod
